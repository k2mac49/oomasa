## 3. 画面構成
### 3.1 タブ（メニュー）
- 「🧾 レジ」「📊 売上」の2タブ。売上タブには会計件数バッジを表示。

### 3.2 レジ画面（横スワイプ2ページ＋スナップ）
- ページA「商品」
  - 上部固定ヘッダー：合計金額（スクロールしても固定）＋「値引き」ボタン。
  - 商品リスト：各行に 商品名／単価／小計／−／個数／＋。
    値引き中は単価に取消線＋実売価格（赤）を表示、行を警告枠。
- ページB「電卓」
  - 合計／預り金／おつり（不足時は警告色）。
  - クイック入金（+1000/+5000/+10000）、テンキー（0-9,00,←）。
  - 「取消」「会計する」。画面内に収まりスクロール不要。
- 下部に「🍢商品／🧮電卓」インジケータ（タップでも切替）。
- 会計確定後は自動で「商品」ページへ戻る。

### 3.3 売上画面
- 営業日（date）・イベント名（text）入力。会計時にこの値で記録。
- サマリ：総売上／営業日数／総会計数。
- 「CSVで書き出す／共有」「全消去」。
- 日付ごとのグループ（新しい順）：日別合計・会計数・販売点数・値引き計、
  品目別（実売・値引き額）、会計履歴。

### 3.4 値引きモーダル（商品ごと）
- 商品ごとに −100（値下げ）／＋100（定価まで戻す）／半額 を設定。
- 表示は「元値 −引いた額→ 実売価格」（例：¥600 −¥100→ ¥500）。
- 定価超過方向（＋）と単価100円以下方向（−）はボタンを無効化（グレーアウト）。
- 「この内容で適用」「すべて解除」「閉じる」。

## 4. データモデル
### 4.1 localStorage キー
- `regmock_txns_v2` … 会計履歴（配列）
- `regmock_disc_v2` … 値引き設定 `{ discounts:[...], date:"YYYY-MM-DD" }`

### 4.2 会計レコード（txn）
```
{
  id:        連番,
  date:      "YYYY-MM-DD",   // 営業日
  event:     "イベント名",
  time:      "HH:MM",
  items: [ { name, price(定価), count, unit(実売単価) } ],
  subtotal:  定価ベース合計,
  discount:  値引き合計(= subtotal - total),
  total:     実売合計,
  received:  預り金,
  change:    おつり
}
```

### 4.3 値引き設定（discounts[i]）
- `null`（値引きなし）／`{type:"amount", value:N}`（単価-N円）／`{type:"half"}`（半額）

## 5. 主要ロジック
### 5.1 実売単価 eff(i)
- 値引きなし → 定価
- half → floor(定価 / 2)
- amount → max(0, 定価 − value)

### 5.2 金額計算
- 合計（実売）= Σ eff(i) × 個数
- おつり = 預り金 − 合計。負なら「不足」を警告表示、会計不可。
- 「会計する」有効条件：1点以上 かつ 預り金 ≥ 合計。

### 5.3 値引きの境界
- ＋100（値上げ）：value = max(0, value−100)。value=0 で無効。
- −100（値下げ）：value = min(定価−100, value+100)。実売100円で無効（0円以下不可）。
- 営業日（date）変更時、値引き設定を自動解除。

### 5.4 会計処理
- items を確定（name/price/count/unit）→ txn を作成し localStorage 追記。
- 個数と預り金をリセット（値引き設定は継続）。売上表示を更新。

### 5.5 集計（売上）
- 日付でグルーピング（降順）。品目別は実売金額を積算、
  値引き額 = Σ(定価−実売)×個数。日別合計 = Σ txn.total。

## 6. CSV仕様
- 文字コード：UTF-8（BOM付き）。改行 CRLF。
- 1行＝1明細（会計×商品）。会計単位の値は各会計の先頭行にのみ記載。
- 列：
  `日付, イベント, 会計No, 時刻, 商品, 通常単価, 適用単価, 単価値引き,
   個数, 金額, 会計小計, 会計値引き計, 会計合計, 預り金, おつり`
- 書き出し：navigator.share（対応時＝iOSで共有シート）→ 非対応時はダウンロード。
- ファイル名：`売上_YYYY-MM-DD.csv`

## 7. PWA / オフライン仕様
- manifest.json：display=standalone、orientation=portrait、テーマ色 #0f172a、アイコン定義。
- sw.js：
  - `CACHE = "regi-cache-v9"`（更新時はこの版数を上げてキャッシュを刷新）。
  - install 時にアプリ一式をプリキャッシュ。fetch はキャッシュ優先＋
    ネット取得分を追記。オフライン時は index.html を返す。
- 更新反映：ファイル更新後、CACHE版数を上げて再デプロイ。端末側は
  ホーム画面アイコン削除→URL再訪→再追加、または Safari のサイトデータ消去で刷新。

## 8. デプロイ手順（GitHub Pages）
1. リポジトリ（Public）に index.html / sw.js / manifest.json / アイコンを配置。
2. Settings → Pages → Deploy from a branch → main / (root)。
3. push すると自動でビルド・再公開（反映まで数分）。
4. 更新時は該当ファイルを上書き commit → push。CACHE版数を上げること。

## 9. 既知の制約
- 単一端末・ローカル保存のみ（多端末同期なし）。恒久保存はCSVで担保。
- iOSはローカル保存を長期未使用時に消す場合がある。
- Service Worker により、旧版がキャッシュされ更新が即時反映されないことがある
  （CACHE版数の更新と端末キャッシュ消去で対応）。
